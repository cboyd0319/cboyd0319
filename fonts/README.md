# Display font

`NotoSansJP-VF.ttf` is unmodified Noto Sans JP 2.004, licensed under [OFL 1.1](OFL.txt).

- [Pinned upstream file](https://github.com/notofonts/noto-cjk/blob/523d033d6cb47f4a80c58a35753646f5c3608a78/Sans/Variable/TTF/Subset/NotoSansJP-VF.ttf)
- The renderer verifies its SHA-256 in [`font.mjs`](../scripts/lib/font.mjs).

ImageMagick uses `config/fonts.conf` for repository-local fonts and cache;
system fonts and network fallback are excluded.
